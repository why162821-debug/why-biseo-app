# why_biseo — 화면

개인용 하루 설계 비서의 **화면 껍데기**입니다. GitHub Pages 로 서빙하려고
따로 떼어낸 저장소라, 여기에는 로그인 화면과 렌더링 코드만 들어 있습니다.

일정·계획·가계부 같은 내용은 이 저장소에 없습니다. 페이지를 열면 먼저
로그인을 요구하고, 통과한 사람에게만 Supabase 에서 데이터를 받아와 그립니다.
접근 제어는 Supabase 의 RLS 가 합니다.

포함된 Supabase 주소와 publishable 키는 설계상 공개되는 값입니다.

본체(동기화·계획 생성 코드)는 별도의 비공개 저장소에 있습니다.
